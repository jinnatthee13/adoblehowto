บทที่ 1 รู้จักหน้าจอและเครื่องมือ

เป้าหมาย: เปิดไฟล์แล้วรู้ว่าอะไรอยู่ตรงไหน และเลื่อนซูมภาพได้คล่อง

ส่วนหลักของหน้าจอ

  • Options bar แถบบนสุด เปลี่ยนตามเครื่องมือที่เลือก เช่น ขนาดและความแข็งของแปรง
  • Toolbar แถบซ้าย รวมเครื่องมือ ไอคอนที่มีสามเหลี่ยมเล็กมุมขวาล่างมีเครื่องมือซ่อนอยู่ ให้กดค้าง
  • Canvas พื้นที่ทำงานตรงกลาง
  • Panels แผงด้านขวา ที่ใช้บ่อยคือ Layers, Properties, Adjustments, History
  • Contextual Task Bar แถบลอยใต้ภาพ แสดงปุ่มลัดตามสิ่งที่ทำอยู่ เช่น พอเลือกวัตถุจะมีปุ่ม Generative Fill ขึ้นมา

ถ้าแผงหาย ไปที่เมนู Window แล้วติ๊กชื่อแผง หากหน้าจอเละให้เลือก Window › Workspace › Reset Essentials

เลื่อนและซูม

กด Space ค้างแล้วลากเพื่อเลื่อนภาพ ใช้ Alt + ลูกกลิ้งเมาส์เพื่อซูม Ctrl 0 พอดีหน้าจอ Ctrl 1 ขนาด 100%

ลองทำ: เปิดรูปใดก็ได้ ซูมเข้าไปที่ดวงตา กลับมาพอดีจอ แล้วกด Ctrl Z เพื่อย้อนการกระทำ

Lesson 1 · Know the screen and tools

Goal: open a file, know where things are, and pan and zoom with ease.

  • Options bar (top) changes with the active tool.
  • Toolbar (left): icons with a small triangle hide more tools; press and hold.
  • Panels (right): Layers, Properties, Adjustments, History.
  • Contextual Task Bar floats under the image and offers the next likely action, such as Generative Fill.

Lost a panel? Open Window and tick its name, or choose Window › Workspace › Reset Essentials.

Move (V)Move layers
Marquee (M)Rectangle or ellipse selection
Object Selection (W)Drag over an object to select it
Crop (C)Trim and recompose
Brush (B)Paint
Type (T)Add text

Hold Space and drag to pan, Alt + scroll to zoom, Ctrl 0 to fit the screen, Ctrl 1 for 100%.

Try it: open any photo, zoom into an eye, fit to screen, then undo with Ctrl Z.

บทที่ 2 สร้างไฟล์ ขนาด และความละเอียด

เป้าหมาย: ตั้งค่าเอกสารให้ตรงกับงานตั้งแต่แรก จะได้ไม่ต้องแก้ทีหลัง

  1. กด Ctrl N เลือกหมวด Web, Print หรือ Photo ตามงาน
  2. ตั้งขนาดด้านขวา เช่น โพสต์ Instagram 1080 × 1350 px
  3. ตั้ง Resolution: งานหน้าจอใช้ 72 ppi งานพิมพ์ใช้ 300 ppi
  4. เลือก Color Mode: งานจอใช้ RGB งานพิมพ์โรงพิมพ์มักใช้ CMYK (ถามโรงพิมพ์ก่อน)

เปลี่ยนขนาดภาพที่มีอยู่

ไปที่ Image › Image Size ติ๊ก Resample ถ้าจะเปลี่ยนจำนวนพิกเซล ส่วน Canvas Size ใช้ขยายหรือลดพื้นที่ผ้าใบโดยไม่ยืดภาพ

การย่อภาพไม่เสียคุณภาพมาก แต่การขยายภาพเล็กให้ใหญ่จะเบลอ ถ้าจำเป็นต้องขยาย ลองเลือก Resample เป็น Preserve Details

ใช้ Smart Object กันภาพเสีย

คลิกขวาที่เลเยอร์ เลือก Convert to Smart Object เมื่อย่อแล้วขยายกลับ ภาพจะไม่เสียรายละเอียด และฟิลเตอร์ที่ใส่ยังแก้ไขภายหลังได้

Lesson 2 · New files, size and resolution

Goal: set up the document correctly from the start.

  1. Press Ctrl N and pick Web, Print or Photo.
  2. Set the size, e.g. 1080 × 1350 px for an Instagram post.
  3. Resolution: 72 ppi for screens, 300 ppi for print.
  4. Color mode: RGB for screens; CMYK is often used for print (ask your printer).

Image › Image Size changes pixel count (tick Resample). Canvas Size enlarges the canvas without stretching the image.

Shrinking loses little quality; enlarging a small image makes it soft. If you must, try Resample: Preserve Details.

Right-click a layer › Convert to Smart Object so you can resize repeatedly without damage and keep filters editable.

ตั้งขนาดให้ถูกตั้งแต่แรก ชีวิตง่ายขึ้นเยอะ

Set the right size first and life gets easier.

บทที่ 3 เลเยอร์ (Layers)

เป้าหมาย: ทำงานแบบแยกชั้น แก้ไขได้ทุกเมื่อโดยไม่ทำลายต้นฉบับ

เลเยอร์เหมือนแผ่นใสวางซ้อนกัน ตัวที่อยู่บนบังตัวที่อยู่ล่าง ดูได้ที่แผง Layers

  • Ctrl Shift N สร้างเลเยอร์ว่าง
  • Ctrl J ทำสำเนาเลเยอร์ หรือคัดลอกส่วนที่เลือกขึ้นเลเยอร์ใหม่
  • รูปดวงตา ซ่อน/แสดงเลเยอร์ กดล็อกเพื่อกันแก้โดยไม่ตั้งใจ
  • ลากเลเยอร์ขึ้นลงเพื่อสลับลำดับ กด Ctrl G จัดกลุ่ม
  • Opacity ปรับความโปร่งใส Blend Mode ปรับวิธีผสมสี เช่น Multiply ทำให้เข้มลง Screen ทำให้สว่างขึ้น

Free Transform

กด Ctrl T จะมีกรอบรอบเลเยอร์ ลากมุมพร้อมกด Shift เพื่อย่อขยายตามสัดส่วน หมุนโดยลากนอกมุม กด Enter เพื่อยืนยัน

ตั้งชื่อเลเยอร์ทุกครั้งที่งานเริ่มเกิน 5 เลเยอร์ ดับเบิลคลิกที่ชื่อเพื่อแก้ งานที่ส่งต่อให้คนอื่นจะอ่านง่ายขึ้นมาก
ลองทำ: เปิดรูป กด Ctrl J ตั้งเลเยอร์ที่ซ้ำเป็น Multiply ลด Opacity เหลือ 40% แล้วดูว่าภาพเปลี่ยนอย่างไร

Lesson 3 · Layers

Goal: work in stacked layers you can edit at any time.

Layers are like transparent sheets stacked on top of each other. Manage them in the Layers panel.

  • Ctrl Shift N new layer; Ctrl J duplicate layer or lift a selection onto its own layer.
  • The eye icon shows or hides; the lock prevents accidents; Ctrl G groups layers.
  • Opacity sets transparency; Blend Mode sets how colors mix (Multiply darkens, Screen lightens).
  • Ctrl T Free Transform: hold Shift to keep proportions, press Enter to confirm.
Name your layers once a file passes about five layers. Double-click the name to rename.
Try it: duplicate a photo layer, set it to Multiply at 40% opacity, and compare.

ตั้งชื่อเลเยอร์ไว้ คนอื่นก็อ่านงานเราออก

Name your layers so others can read your file.

บทที่ 4 เลือกพื้นที่และเลเยอร์มาสก์

เป้าหมาย: ตัดพื้นหลังออกโดยยังย้อนกลับได้

วิธีเลือก

  • Object Selection (W): ลากกรอบคร่อมวัตถุ เหมาะกับคน สัตว์ สิ่งของ
  • Select Subject: ปุ่มใน Options bar เลือกตัวแบบหลักอัตโนมัติ
  • Lasso (L): ลากเส้นรอบเอง ใช้เก็บรายละเอียด
  • กด Shift เพื่อเพิ่มพื้นที่ กด Alt เพื่อลบพื้นที่

ตัดพื้นหลังด้วยมาสก์

  1. เลือกวัตถุด้วย Select Subject
  2. กดปุ่ม Add Layer Mask (ไอคอนสี่เหลี่ยมมีวงกลม) ที่ท้ายแผง Layers
  3. พื้นหลังจะถูกซ่อน ไม่ได้ถูกลบ
  4. เลือกช่องมาสก์ ใช้แปรง ดำ ซ่อนเพิ่ม ขาว เอากลับมา กด X สลับสี

ขอบหยาบ ให้ดับเบิลคลิกมาสก์เพื่อเปิด Properties แล้วใช้ Feather หรือเลือก Select and Mask เพื่อปรับขอบผมให้เนียน

จำง่ายๆ “ดำซ่อน ขาวโชว์” ผิดเมื่อไรก็สลับสีแล้วระบายใหม่ได้ ต่างจากยางลบที่ลบแล้วหายถาวร

Lesson 4 · Selections and layer masks

Goal: remove a background without destroying anything.

  • Object Selection (W): drag a box around a person, animal or item.
  • Select Subject: one click in the Options bar.
  • Lasso (L): draw by hand for fine details. Shift adds, Alt subtracts.
  1. Select the subject.
  2. Click Add Layer Mask at the bottom of the Layers panel.
  3. The background is hidden, not deleted.
  4. Paint on the mask: black hides, white reveals; press X to swap.

For rough edges, use Feather in Properties or Select and Mask to refine hair.

จำไว้นะ ดำซ่อน ขาวโชว์!

Remember: black hides, white reveals!

บทที่ 5 ปรับสีและแสง

เป้าหมาย: แก้ภาพมืด ซีด สีเพี้ยน แบบที่แก้ภายหลังได้

ใช้ Adjustment Layer จากแผง Adjustments หรือปุ่มวงกลมครึ่งดำครึ่งขาวท้ายแผง Layers แทนการไปที่ Image › Adjustments โดยตรง เพราะแยกชั้นและมีมาสก์ในตัว

Levels / Curvesปรับความสว่าง คอนทราสต์ Curves ละเอียดกว่า
Vibranceเพิ่มสีสันโดยไม่ทำสีผิวเพี้ยน
Hue/Saturationเปลี่ยนเฉดและความสดแยกตามช่วงสี
Color Balanceเติมโทนอุ่นหรือเย็น
Camera Raw Filterปรับภาพแบบเดียวกับ Lightroom

ลำดับที่แนะนำ

  1. ปรับแสงโดยรวมด้วย Levels ดึงแถบเล็กด้านขาวและดำเข้าหาขอบกราฟ
  2. ปรับคอนทราสต์ด้วย Curves ดึงเป็นรูปตัว S อ่อนๆ
  3. แก้สีผิดด้วย Color Balance หรือ Hue/Saturation
  4. เพิ่มความสดด้วย Vibrance
ถ้าอยากให้เอฟเฟกต์กระทบแค่เลเยอร์ล่างตัวเดียว คลิกขวาที่ Adjustment Layer แล้วเลือก Create Clipping Mask

Lesson 5 · Color and light

Goal: fix dark, flat or off-color photos non-destructively.

Use Adjustment Layers (Adjustments panel or the half-black circle in Layers) instead of Image › Adjustments: they sit on their own layer and include a mask.

  • Levels / Curves: brightness and contrast; Curves is finer.
  • Vibrance: more color without wrecking skin tones.
  • Hue/Saturation and Color Balance: fix or warm and cool the color.
  • Camera Raw Filter: Lightroom-style controls.

Suggested order: Levels › Curves (gentle S) › color fixes › Vibrance.

To affect only the layer below, right-click the adjustment and choose Create Clipping Mask.

ใช้ Adjustment Layer ไว้ก่อน ไม่มีเสียใจทีหลัง

Use Adjustment Layers and skip the regrets.

บทที่ 6 รีทัชและลบสิ่งที่ไม่ต้องการ

เป้าหมาย: ลบสิว รอยเปื้อน หรือคนที่เดินเข้ามาในภาพ

  • Remove Tool: ระบายทับสิ่งที่ต้องการลบแล้วปล่อยเมาส์ โปรแกรมเติมพื้นหลังให้ เหมาะกับวัตถุเล็กถึงกลาง
  • Spot Healing Brush: แตะที่สิวหรือฝุ่นจุดเดียวก็หาย
  • Clone Stamp (S): กด Alt คลิกเลือกต้นทาง แล้วระบายทับตำแหน่งที่ต้องการ ควบคุมได้เต็มที่
  • Content-Aware Fill: เลือกพื้นที่ แล้ว Edit › Content-Aware Fill
ทำรีทัชบน เลเยอร์ว่างใหม่ และในตัวเครื่องมือเลือก Sample: Current & Below (หรือ All Layers) ถ้าไม่พอใจก็ลบเลเยอร์นั้นทิ้ง ต้นฉบับยังอยู่ครบ

ผิวหน้า ห้ามลบริ้วรอยจนเรียบเป็นพลาสติก ลดความแรงด้วย Opacity ของเลเยอร์รีทัชเหลือ 50–70% จะดูเป็นธรรมชาติกว่า

Lesson 6 · Retouching and removing things

Goal: remove blemishes, dust or people who walked into the shot.

  • Remove Tool: paint over the unwanted item and release; the background is filled in.
  • Spot Healing Brush: tap a pimple or dust speck.
  • Clone Stamp (S): Alt+click a source, then paint where needed.
  • Content-Aware Fill: select an area, then Edit › Content-Aware Fill.
Retouch on a new empty layer with Sample: Current & Below (or All Layers). Unhappy? Delete that layer and the original is untouched.

Do not smooth skin until it looks like plastic; lower the retouch layer to 50–70% opacity.

รีทัชบนเลเยอร์ใหม่ ปลอดภัยสุดๆ

Retouch on a new layer. Safe and sound.

บทที่ 7 ข้อความและรูปทรง

เป้าหมาย: ทำโปสเตอร์หรือแบนเนอร์ที่อ่านง่าย

  1. กด T คลิกบนภาพแล้วพิมพ์ กด Ctrl Enter เพื่อยืนยัน
  2. เปลี่ยนฟอนต์ ขนาด สี ที่ Options bar หรือแผง Properties
  3. ลากเมาส์เป็นกล่องเพื่อสร้าง Paragraph Text ที่ตัดบรรทัดอัตโนมัติ
  4. ปรับ Tracking (ระยะตัวอักษร) และ Leading (ระยะบรรทัด) ที่แผง Character

หลักจัดตัวอักษรให้อ่านง่าย

  • ใช้ฟอนต์ไม่เกิน 2 แบบ แยกหัวข้อกับเนื้อหาด้วยขนาดและน้ำหนัก
  • ข้อความไทยควรเว้นบรรทัดประมาณ 1.4–1.6 เท่าของขนาดตัวอักษร เพราะสระและวรรณยุกต์ซ้อนสูง
  • ถ้าข้อความอยู่บนรูปแล้วอ่านยาก ใส่แผ่นสีโปร่งแสงคั่นกลาง หรือใช้เงา (Drop Shadow) เบาๆ

รูปทรง

ใช้ Rectangle Tool (U) วาดกรอบหรือปุ่ม รูปทรงเป็นเวกเตอร์ ย่อขยายไม่แตก ปรับมุมโค้งได้ที่แผง Properties

Lesson 7 · Text and shapes

Goal: build a poster or banner that reads clearly.

  1. Press T, click the image and type; Ctrl Enter confirms.
  2. Change font, size and color in the Options bar or Properties.
  3. Drag a box for Paragraph Text that wraps automatically.
  4. Adjust tracking and leading in the Character panel.
  • Use at most two fonts; separate headings from body by size and weight.
  • Keep line spacing around 1.4–1.6× for Thai text with stacked vowels and tone marks.
  • If text is hard to read on a photo, add a translucent panel or a soft Drop Shadow.

Shapes (U) are vectors: scale freely, adjust corner radius in Properties.

ฟอนต์ไม่เกินสองแบบ งานจะดูสะอาดตา

Two fonts at most keeps things clean.

บทที่ 8 Generative AI และส่งออกงาน

เป้าหมาย: ใช้ AI ช่วยเติมภาพ และบันทึกไฟล์ให้ถูกชนิด

Generative Fill และ Generative Expand

  1. เลือกพื้นที่ด้วย Lasso หรือ Object Selection
  2. กด Generative Fill บน Contextual Task Bar
  3. พิมพ์สิ่งที่ต้องการ เช่น “ท้องฟ้ายามเย็น” ปล่อยว่างไว้ถ้าต้องการให้ลบวัตถุ
  4. เลือกผลลัพธ์ที่ชอบจากแผง Properties ผลลัพธ์จะเป็นเลเยอร์แยก

Generative Expand: ใช้ Crop Tool ลากกรอบให้ใหญ่กว่าภาพ แล้วกด Generate เพื่อขยายฉากต่อออกไป

ฟีเจอร์เหล่านี้ต้องล็อกอิน Adobe และใช้เครดิต Generative ตามแพ็กเกจที่สมัคร รายละเอียดของรุ่นและโมเดลที่ใช้ได้เปลี่ยนตามอัปเดต ให้ดูหน้า Help ในโปรแกรมประกอบ ภาพจาก AI ควรตรวจมือ ตัวอักษร และรายละเอียดเล็กๆ ก่อนใช้งานจริงเสมอ

Lesson 8 · Generative AI and exporting

Goal: use AI to fill in an image and save the right file type.

  1. Select an area with Lasso or Object Selection.
  2. Click Generative Fill on the Contextual Task Bar.
  3. Type what you want, e.g. “evening sky”; leave it blank to remove an object.
  4. Pick a result in Properties; each one is a separate layer.

Generative Expand: drag the Crop tool beyond the image and click Generate.

These features need an Adobe sign-in and use generative credits depending on your plan. Available models vary by update, so check in-app Help. Always inspect AI results for hands, text and small details.

Export: PSD to keep editing (File › Save As); JPG for photos, PNG for transparency, WebP for small web images (File › Export › Export As); PDF or TIFF for print.
